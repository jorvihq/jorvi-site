# jorvi.io

The Jorvi website, as served.

Built output only. Every file here is generated, so changes belong upstream rather than in
this repository.

Jorvi is payments infrastructure for the self-custody era: merchants charge a wallet on a
schedule, under a mandate the holder signs once and can cap, pause, or revoke at any time.
